## 📄 Website Pages & Features
* **`index.html` (Home):** Welcomes visitors with the Cafe Corner logo, highlights today's favorite menu items, and includes a quick-order button.
* **`menu.html` (Full Menu):** Displays categorized tables for **Drinks**, **Snacks**, and **Desserts** with descriptions and pricing.
* **`order.html` (Order Online):** Features an interactive order and table reservation form with automatic bill calculation via JavaScript.
* **`about.html` (About & Contact):** Shares the cafe's background, opening hours, location, and an interactive customer feedback form.
* **`style.css`:** Unified stylesheet implementing a pastel pink and dark brown color palette across all pages.

## 🛠️ Technologies Used
* **HTML5** – Structure and semantic page layout
* **CSS3** – Custom styling, tables, navigation bar, and forms
* **JavaScript** – Interactive order alerts, dynamic price calculation, and form feedback
